# Theo trading signals (TradingView)

A Pine Script v5 indicator that scores a four-point checklist and calls BUY or SELL when enough points agree:

1. RSI oversold or overbought
2. 10 / 20 moving average cross
3. Price outside the Bollinger Bands
4. Price above or below the 200-week moving average

Three of four (configurable) triggers a signal. It also labels the current market cycle stage (beta).

**Not financial advice and not auto-trading.** It is a notification tool; signals are meant to be reviewed before any action.

Paste `theo-trading-signal.pine` into the TradingView Pine Editor and add it to a chart.
